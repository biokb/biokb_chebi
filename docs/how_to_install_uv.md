# How to install uv

## Why you should install uv

`uv` is a powerful library that allows you to efficiently handle asynchronous I/O operations in Python. It can ***significantly improve the performance*** of your applications by enabling non-blocking network and file system operations.

## Installation Instructions

=== "Windows"

    Open PowerShell (not CMD) and run the following command:
    ```powershell
    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh | iex"
    ```

=== "macOS"
    Open your terminal and run the following command:
    ```bash
    curl -LsSf https://astral.sh | sh
    ls -la
    ```

=== "Linux"
    Open your terminal and run the following command:
    ```bash
    curl -LsSf https://astral.sh | sh
    ```
